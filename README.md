# 江南古村 · 3D 国风乡村地图生成器

一键生成一座可俯瞰、可把玩的江南古村。**单文件、零依赖、双击即玩。**

---

## 在线体验

**[▶ 点这里直接打开在线版](https://cyhnanfeng.github.io/jiangnan-village-3d/)**

（GitHub Pages，由仓库根目录的 `index.html` 提供；与本地成品完全同一份代码。）

## 立即开始

双击打开 **`index.html`**（约 1.06 MB，Three.js 已内联，断网也能玩）。

| 操作 | 效果 |
|---|---|
| 点左侧朱红「生成」印章 / 按 `R` | 重新生成一座全新的村落 |
| 鼠标拖拽 | 旋转视角 |
| 滚轮 | 拉近拉远 |
| 空格 | 环绕换方位 |
| 点击房屋 / 宝塔 / 牌坊 | 弹出该建筑的信息卡 |
| 「换时辰」 | 晨雾 / 正午 / 夕照 / 夜泊 循环切换 |
| 「俯瞰」/「入村」 | 两个预设机位 |
| 「存图」 | 导出当前画面 PNG |
| 地址栏 `#种子号` | 同一个种子生成同一座村，可分享 |

每次点击都会重新组合：**5 种水系布局 × 4 种季节 × 4 种时辰**，共 80 种风格组合，另加随机密度、河道宽度、街巷间距、树木分布。

## 八条硬性规约

生成时保证，并由独立校验函数逐条复核（界面右侧「八条规约」可展开看实测数据）。

| 编号 | 规约 | 实现方式 |
|---|---|---|
| R1 | 河与路必正交 | 所有河道段、街巷段强制轴对齐（x/z 向），生成后复检 |
| R2 | 路近水锁直 | 临水主街为不中断、不转折的直街，逐格验证连通 |
| R3 | 房屋周围一圈禁房 | 占地外扩 1 格（含对角）检测，确保 8 邻域无其他房屋 |
| R4 | 房屋门朝道路 | 门所在面正前方 1 格必须是街/巷/桥面/门前场 |
| R5 | 农田近路/水/宅 | 每块田边界 2 格内必有路、水或宅 |
| R6 | 宝塔距最近民居 ≥16 格 | 先定塔址，17 格内一律不落民居；实测 17.0~18.0 格 |
| R7 | 主路两端 85% 立牌坊 | 每端按 0.85 概率，再校正整体比例至 85% |
| R8 | 树在边缘/水边/树丛加密 | 密度场 = 基础 + 边缘衰减 + 水岸加成 + 高斯树丛 |

自动化测试：

```bash
node tools/map-test.mjs 30    # 30 轮随机种子，全部规约必须通过
node tools/style-test.mjs     # 80 种风格组合，全部规约必须通过
```

## 14 个模型

每个模型由独立子任务完成，通过同一套契约验收（4 个 seed 无 NaN、贴地、材质全部来自共享材质库、随机可复现）。

| 文件 | 模型 | 要点 |
|---|---|---|
| `house.js` | 江南民居 | 石勒脚、白墙收分、马头墙（阶梯+墀头翘角）、硬山瓦顶、石库门、门簪门钉、花窗、檐柱雀替、水缸灯笼 |
| `hall.js` | 宗祠/厅堂 | 三开间两进、须弥座台基、三出陛、檐柱斗拱、隔扇门、匾额、石狮 |
| `shop.js` | 临水商铺 | 两层、排门板、柜台货品、挑出招牌幌子、二层挑台美人靠、腰檐 |
| `bridge.js` | 单孔石拱桥 | 放射状梯形条石拱圈、券脸石、分水尖、抛物线桥面、望柱栏板、桥心石 |
| `bridgeFlat.js` | 平桥/石板桥 | 条石桥墩、分水尖、错缝桥板、矮石栏或木栏、抱鼓石 |
| `paifang.js` | 四柱三间三楼牌坊 | 收分柱、夹杆石抱鼓、斗拱、三间瓦顶、匾额、柱联 |
| `pagoda.js` | 七层八角宝塔 | 八角收分、层层腰檐、平座栏杆、斗拱、铜铃、塔刹相轮宝珠 |
| `tree.js` | 树木 7 品种 | 香樟/垂柳/松/竹丛/枫/桃梅/桂，冠幅由噪声团块叠成 |
| `boat.js` | 乌篷船 | U 形截面船壳、错缝板条、半圆筒乌篷篾条、橹桨竹篙缆绳 |
| `field.js` | 农田 4 作物 | 水稻（田埂+浅水+稻株行列）、菜畦、油菜花、桑田 |
| `wharf.js` | 河埠头 | 石阶入水、垂带石、系船石缆绳、矮墙陶罐、晾衣、洗衣石 |
| `props.js` | 村口道具 7 种 | 水井辘轳、石磨草棚、柴堆、晾晒架、酒坛群、灯笼杆、土地庙 |
| `pavilion.js` | 路亭 / 水榭 | 攒尖亭（美人靠石桌凳）或水榭（屏风琴桌临水石阶） |
| `corridor.js` | 沿街廊棚 | 木柱列、单坡出檐、排门板柜台店招、青石板街面排水沟 |

## 技术结构

```
jiangnan-village-3d/
├─ index.html              ← 成品（单文件，双击即玩；也是 GitHub Pages 入口）
├─ README.md
├─ build.mjs               构建脚本：src + models + three.min.js → 单 HTML
├─ three.min.js            Three.js r160（UMD，内联进成品）
├─ src/
│  ├─ 00-utils.js          确定性随机、静态合并 Batch、Instancer、动画注册表
│  ├─ 05-kit.js            材质库（程序化 Canvas 贴图）+ 共用构件（瓦作/木作/石作/植被）
│  ├─ 10-map.js            地图生成核心（河网/街巷/桥/塔/民居/牌坊/农田/树）+ 规约校验
│  ├─ 20-world.js          世界构建（地形/水面/驳岸/街巷/建筑实例化/远山/灯光）
│  ├─ 30-app.js            渲染器/相机/交互/UI/生成流水线
│  ├─ index.template.html
│  └─ style.css
├─ models/                 14 个模型（见上表）
├─ docs/MODEL_CONTRACT.md  模型契约（API、坐标系、尺寸、验收标准）
└─ tools/                  Node 无浏览器校验工具
   ├─ boot.mjs             加载运行时（供校验脚本用）
   ├─ verify.mjs           单模型验收（4 seed、NaN、贴地、三角面/网格/材质预算）
   ├─ map-test.mjs         地图规约批量测试
   ├─ style-test.mjs       80 种风格组合测试
   ├─ preview-build.mjs / preview.html   模型预览页
   ├─ shot.mjs / console.mjs / probe.mjs 无头 Chrome 截图与调试
```

### 性能设计

- **Instancer**：重复构件（房屋/树/田/道具）模板只合并一次，实例用 `InstancedMesh` 批量绘制
- **Batch**：一次性构件（塔/桥/牌坊/廊棚/亭）按材质合并成静态网格
- 单次生成约 **3~8 秒**、50~80 万三角面、**约 46 个 draw call**
- 生成流程分帧执行（`requestAnimationFrame` 分段），带进度条，不卡界面

### 重新构建

```bash
node build.mjs
# 同时输出 index.html（本仓库根目录）与上级目录的独立成品 江南古村.html
```

### 修改后自检

```bash
node tools/verify.mjs <模型名> --file models/<模型名>.js
node tools/map-test.mjs 30
node tools/style-test.mjs
```

## 说明

- 所有贴图都是运行时用 Canvas 程序化生成（墙斑、瓦垄、木纹、石材、水面法线），不含任何外部图片资源。
- 无头 Chrome 截图里中文匾额显示为黑板，是因为该环境缺中文字体；真实浏览器正常显示文字。
- 桌面端 Chrome / Edge 体验最佳（需要 WebGL）。
